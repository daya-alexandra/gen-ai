# Проверка подготовки

19.09.2026, Python 3.12, Linux. Команда: `python -m unittest test_lab2 -v`.

**12 тестов пройдены.** Проверены дата из будущего, отсутствие аспекта, шесть уникальных аспектов, цитата из чужого отзыва, изменение отрицания и числа, полнота разбиения, учёт cache hit в тарифе, ограничитель бюджета до отправки запроса, безопасная обработка API-ошибки без повторов, ровно четыре попытки при max_retries=3, отказ от возобновления при изменении конфигурации и полный конвейер на заглушке.

Интеграционный тест проверяет ветку judge < 0,7 → изменённый REDUCE → повторный judge, отдельный контроль A99, отсутствие повторных вызовов при возобновлении, совпадение сохранённых результатов с ответами и отказ проверять тестовую заглушку как настоящий API-прогон. Изменение результата IE обнаруживается проверкой.

Для тестов используются временные каталоги, которые удаляются после выполнения. Их оценки и heatmap не публикуются в `output/`. Windows-сценарий подготовлен для CMD, но на Windows в этой среде не запускался.

**Реального прогона DeepSeek для лабораторной № 2 пока нет.** Его качество, токены, стоимость и ошибки будут проверены по архиву результатов после запуска с ключом пользователя.
