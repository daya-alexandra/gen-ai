## Как читать статусы

`submission_status.json` создан конвейером и сохранён без изменений. Его значение `natural_error_examples_found: 0` означает, что автоматический список distortions оказался пуст. После сверки исходников найдены два примера потери контекста (R24 и R29), описанные в `report_review.json` с точными полями и исходными цитатами. У R29 неточность относится к IE и уже устранена в итоговой сводке.

`выводы_авто.md` — исходный автоматически собранный текст, `выводы.md` — доработанный отчёт. `diagnostic_*.json` содержат отдельный эксперимент с намеренно внесёнными ошибками; его примеры не выдаются за естественные ошибки модели.

## Воспроизводимость

`api_trace.jsonl`, `cache/`, `run.json`, `budget.json` и `continuation.json` сохранены побайтно. `continuation.json` описывает профиль, с которым завершён REDUCE, и 17 повторно использованных этапов. Параметры, код, входной корпус, ответы и численные показатели проверяются из папки lab2_text командой:

```bat
python recovery\continue_lab2.py --verify-only
```

Проверка не отправляет API-запросы. Она устанавливает согласованность локальных файлов, а не подтверждает биллинг на стороне провайдера. Протокол проверки находится в [VALIDATION.md](../VALIDATION.md).
