# Результаты ещё не получены

В этом каталоге пока нет результатов реального API-прогона второй лабораторной. Локальные тесты используют явно обозначенные заглушки и не публикуются как эксперимент.

Запуск: `python pipeline.py`. После успешного завершения появятся `reviews.json`, `aspects.json`, `heatmap.png`, `map_summaries.json`, `summary.json`, `judge_report.json`, `discovered_aspects.json`, `metrics.json`, `выводы.md` и журнал API. Если нужен повторный REDUCE, сохранятся обе версии и оба вердикта.

Перед сдачей нужно выполнить `python verify_results.py`, прочитать `выводы.md` и проверить `submission_status.json`. Диагностические примеры искусственно внесённых ошибок находятся в отдельных `diagnostic_*.json` и не подменяют ошибки основного прогона.
