# Учебный корпус «ПланДень»

30 синтетических отзывов о **вымышленном** мобильном планировщике задач. Тексты подготовлены с помощью ИИ 19.09.2026 специально для этой лабораторной. Это не выгрузка магазина приложений и не реальные персональные данные. Имена — вымышленные обозначения авторов.

В задании преподавателя разрешена генерация отзывов через LLM. Подготовка этого корпуса выполнена отдельно от API-эксперимента; его стоимость не включается в `response.usage` DeepSeek. Сам конвейер анализа ещё необходимо запустить через API.

`reviews.jsonl` содержит по одному JSON-объекту на строку: устойчивый `review_id` и исходный `text`. Метаданные внутри текста извлекает модель; пропуски не заполняются заранее. Намеренно включены смешанные оценки, отрицания, разные версии, неоднозначные причины сбоев и дополнительные темы: доступность, приватность, совместная работа, экспорт, офлайн-режим.

Этот корпус подходит для отладки, но не для оценки удовлетворённости реальной аудитории. Наличие правдоподобного отзыва не означает существования такого приложения или пользователя.
