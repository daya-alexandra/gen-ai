# Лабораторная работа № 3. Анализ текстовых отзывов

Работа выполнена по заданию семинара 3. Цель — разработать конвейер анализа отзывов в новой предметной области и объединить извлечение информации, аспектный анализ, Map-Reduce и LLM-as-judge.

В качестве предметной области выбраны отзывы о вымышленном приложении-планировщике «ПланДень». Корпус содержит 30 синтетических отзывов.

## Реализация

Конвейер включает следующие этапы:

1. структурированное извлечение наблюдений из отзывов;
2. оценку шести фиксированных аспектов по шкале от −2 до +2;
3. параллельную обработку фрагментов и итоговую сводку Map-Reduce;
4. отдельную оценку сводки моделью-судьёй;
5. повторное формирование сводки при оценке ниже 0,7;
6. поиск дополнительных тем за пределами фиксированного перечня аспектов;
7. программную проверку принадлежности каждой цитаты указанному отзыву.

Структурированный вывод проверяется Pydantic-схемами. Повторные попытки ограничены параметром `max_retries=3`. Принятые ответы сохраняются в кэше и повторно не запрашиваются при продолжении того же эксперимента.

## Запуск

Требуется Python 3.10 или более новая версия. На Windows используется файл `RUN_LAB2.cmd`. Его техническое имя соответствует каталогу `lab2_text`; в общей нумерации курса это лабораторная работа № 3.

Сценарий выполняет установку зависимостей, локальные тесты, основной эксперимент, проверку и формирование `lab2_results.zip`. API-ключ задаётся в локальном файле `.env` и не включается в архив.

Ручной запуск из каталога работы:

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
set PYTHONUTF8=1
.venv\Scripts\python.exe -m unittest test_lab2 -v
.venv\Scripts\python.exe recovery\continue_lab2.py
.venv\Scripts\python.exe verify_results.py
.venv\Scripts\python.exe collect_results.py
```

При отсутствии `.env` он создаётся на основе `.env.example`. Повторный запуск продолжает незавершённый эксперимент по сохранённому кэшу. Для независимого эксперимента используется отдельный каталог:

```bat
python recovery/continue_lab2.py --output output_v2
```

## Ограничения

Оценка LLM-as-judge не является независимой экспертной разметкой. Проверка цитат подтверждает буквальное присутствие фрагмента в исходном отзыве, но не гарантирует правильность его интерпретации. Стоимость рассчитывается по сохранённому использованию токенов и опубликованным тарифам; это оценка, а не банковский документ.
