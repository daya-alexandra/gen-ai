## Запуск на Windows

1. Скачай обновлённый репозиторий: на странице `daya-alexandra/gen-ai` нажми **Code → Download ZIP**, распакуй архив и открой папку `lab2_text`.
2. Если ключ уже записан в `.env` первой работы на твоём компьютере, скопируй **только этот файл** в `lab2_text`. Сам ключ никому отправлять не нужно. Если рядом с `lab2_text` находится `.env` или `lab1_verified/.env`, сценарий подхватит его автоматически.
3. Дважды нажми **RUN_LAB2.cmd**. Сценарий создаст окружение, установит зависимости и выполнит локальные тесты. Если ключа ещё нет, откроется Блокнот: замени `PASTE_YOUR_KEY_HERE` после `LLM_AUTH_TOKEN=`, сохрани `.env`, закрой Блокнот и продолжи.
4. После тестов пойдут **реальные платные запросы** к DeepSeek с ключом из `.env`. Результаты сохраняются по мере выполнения. При остановке исправь указанную причину и снова запусти тот же файл: принятые ответы берутся из кэша.
5. После успешной проверки появится **lab2_results.zip**. Он содержит только результаты, без ключа и окружения. Этот архив можно передать для финальной проверки и загрузки результатов на GitHub.

Python 3.10 или новее должен быть установлен. Для запуска команд вручную открой `cmd` **из этой папки** и выполняй по одной строке:

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
notepad .env
set PYTHONUTF8=1
.venv\Scripts\python.exe -m unittest test_lab2 -v
.venv\Scripts\python.exe recovery\continue_lab2.py
.venv\Scripts\python.exe verify_results.py
.venv\Scripts\python.exe collect_results.py
```

Команда `copy .env.example .env` нужна **только при отсутствии** заполненного `.env`. Не заменяй ею уже сохранённый ключ.

## Что проверяет конвейер

| Требование | Реализация |
|---|---|
| Своя схема | `schema.py`: Review, Issue в форме Claim, Aspects, Summary, JudgeReport; Optional, Literal, field_validator даты |
| Свои промпты | `prompts.py`: исходные отзывы трактуются как данные; сохраняются оговорки и отрицания |
| IE | По 5 отзывов на запрос; все входные ID должны присутствовать ровно один раз |
| Аспекты | Шесть фиксированных аспектов, оценки −2…+2; отсутствие упоминания — null |
| Map-Reduce | Разбиение по целым отзывам, до 3 MAP-запросов параллельно; REDUCE использует цитаты из MAP |
| Judge | Отдельный запрос с полными исходными отзывами; каждый action_id получает вердикт |
| Низкая оценка | При score < 0,7 изменённый REDUCE получает замечания судьи; обе версии сохраняются |
| Цитаты | `check_quotes`: дословная цитата должна принадлежать указанному review_id |
| Autodiscovery | 3–10 тем, соответствие фиксированным аспектам либо кандидат за пределами Literal |
| Учёт | `response.usage`, response_id, модель ответа, ошибки каждой попытки, стоимость и время |
| Повторы | `make_client()` / `response_model` / `max_retries=3`: первая попытка + максимум 3 исправления |
| Возобновление | Кэш валидных ответов; изменение кода/данных/модели требует отдельной папки результата |

Дополнительный профиль `recovery/continue_lab2.py` ограничивает REDUCE до 3–5 наблюдений и 2–3 действий с максимум двумя цитатами на пункт. Его параметры и хеш исполняемого кода фиксируются в `continuation.json`, отдельно от неизменного базового конвейера. Лимит сводки увеличен до 12000 токенов. RUN_LAB2.cmd теперь запускает этот профиль, затем проверяет результаты и собирает архив.

## Результаты и ограничения

В `output/` сохранены все обязательные артефакты. Итоговый `выводы.md` с тремя разделами размещён также в корне лабораторной, как требует задание. Проверка `verify_results.py` сверяет вход, хеши кода, принятые ответы, кэш, конечные JSON, цитаты, токены и метрики. Она не подтверждает серверную подлинность запросов или списания в кабинете провайдера.

Цена оценивается диапазоном off-peak…peak по [официальным тарифам DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/), проверенным 19.09.2026. Лимит по умолчанию — **$1 оценочных расходов и 120 попыток для этой лабораторной**. Это программный ограничитель по опубликованному тарифу, а не банковский лимит. Если был скопирован старый `.env`, проверь значения `LLM_BUDGET_USD` и `LLM_MAX_CALLS` в нём.

Модель и судья используют `deepseek-flash` в отдельных запросах без thinking; их согласие не заменяет независимую разметку. Словарная проверка цитат не обнаруживает все смысловые искажения.

`diagnostic_summary.json` специально содержит три ложных утверждения и неподкреплённую рекомендацию A99. Её судья оценивает отдельно. Эти тестовые ошибки **не выдаются за ошибки основного API-прогона**. После сверки исходников в отчёт включены два естественных случая потери контекста: R24 в итоговой сводке и R29 на этапе IE. Автоматический список distortions пуст; дополнительные находки записаны отдельно в output/report_review.json.

**Числовые критерии текущего прогона выполнены; разбор двух неточностей, вердикта A3 и новых тем включён в отчёт.** Исходные ответы и численные оценки сохранены. Для просмотра и проверки опубликованных результатов API-ключ не требуется. Повторный запуск конвейера пересоздаёт автоматически собранный output/выводы.md; окончательный отчёт в корне лабораторной остаётся отдельным документом.

Для нового эксперимента: `python recovery/continue_lab2.py --output output_v2`. Старые результаты сохраняются. Для проверки такого эксперимента: `python recovery/continue_lab2.py --output output_v2 --verify-only`.
