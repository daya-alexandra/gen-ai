Версия репозитория: `5a1325dde011413662b76cab39b906572c8c6d40`.

В этом решении сохранена схема клиента преподавателя: JSON mode → извлечение JSON →
валидация Pydantic → обратная связь при ошибке. Сохранён вызов `make_client()` и
аргументы `response_model=Application`, `max_retries=3`. Клиент сокращён до функций,
нужных для задания, и доработан: фиксируются все попытки; передаётся `max_tokens`;
TLS проверяется; SDK не делает дополнительных скрытых повторов; сетевые ошибки
отделены от ошибок структуры данных. Заголовки авторизации и ключи не журналируются.

Схемы предметной области, промпты, расписание генерации, сохранение прогресса,
анализ и тесты подготовлены для этой работы.
