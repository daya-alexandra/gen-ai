В основном прогоне получено 50 синтетических заявок через DeepSeek API: все 50 прошли повторную проверку схемы. Для борьбы с концентрацией по городам применены квоты — по 5 заявок на каждый из 10 городов, в перемешанном порядке. Максимальная доля города снизилась с 18% в сравнительном случайном прогоне до 10%. По специальностям квоты не задавались: максимум составил 32% (16 специалистов по логистике) против 30% в случайном прогоне; оба значения ниже порога 35%. Представлены 7 из 8 разрешённых специальностей, учителей нет. Географический баланс не устранил другие перекосы: у 32 из 50 заявителей возраст 34 года (64%), всего встречаются лишь пять разных возрастов в диапазоне 29–47 лет, пять ФИО повторяются по два раза. Полностью одинаковых заявок нет. Запоминание пяти последних ФИО в промпте не обеспечило уникальность всего набора. Для следующего эксперимента можно добавить квоты специальностей и возрастных групп, проверку всех ранее использованных ФИО и справочник районов. Эти изменения пока не проверялись. По одному прогону на стратегию нельзя приписывать различия специальностей только стратификации; выборка не представляет реальных заявителей.

Пользовательские `@field_validator` проверяют допустимый город, формат ФИО, соответствие стажа возрасту и год выпуска с допущением об окончании обучения не раньше 20 лет. По журналам обоих прогонов они не обнаружили нарушений: все 100 ответов приняты с первой попытки, ошибок JSON/Pydantic, API и несовпадений с назначенным городом не было. Поэтому на реальных ответах в этом эксперименте исправляющие повторы не потребовались. Интерфейс `make_client()` использован с `response_model=Application` и `max_retries=3`; обработка некорректных ответов проверена отдельно в локальных тестах и не включена в статистику ошибок модели. CSV совпадает с исходными ответами и checkpoint, ручная правка заявок не применялась. Пороговые требования задания соблюдены, но валидная структура сама по себе не гарантирует разнообразие, точную географию районов или реалистичность всех сочетаний профессии и курса.
