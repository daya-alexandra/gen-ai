# Лабораторная работа № 2. Генерация синтетических заявок на программы ДПО

Работа выполнена по заданию семинара 2. Цель — разработать воспроизводимый конвейер генерации синтетических заявок со структурированной валидацией и контролем разнообразия выборки.

## Постановка задачи

Требовалось получить 50 валидных заявок, описанных Pydantic-схемами, и проверить ограничения предметной области. В итоговом наборе должны быть представлены десять городов, а доля одной специальности не должна превышать 35%.

Дополнительно реализованы два режима формирования выборки:

- стратифицированная генерация с квотой по пять заявок на каждый город;
- случайная генерация для сопоставления распределений.

## Реализация

Проверка объектов выполняется в `schema.py` с использованием типов `Literal`, диапазонов значений и `field_validator`. Генератор сохраняет каждый принятый объект, исходный ответ модели, параметры запуска и события валидации. Стратифицированный режим обеспечивает требуемое представительство городов, не изменяя полученные от модели значения остальных полей.

## Результаты

Генерация выполнена 19 сентября 2026 года через API DeepSeek.

| Показатель | Стратифицированный набор |
|---|---:|
| Валидные заявки | 50 |
| Число городов | 10 |
| Заявок на каждый город | 5 |
| Максимальная доля специальности | 32% |
| Допустимый предел | 35% |

Случайный набор из 50 заявок сохранён отдельно и используется только для сравнения распределений.

## Проверка сохранённых результатов

Проверка выполняется без обращения к API:

```bat
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py check
.venv\Scripts\python.exe run.py verify
```

Ожидаемый статус итоговой проверки: `passed`. Команды проверяют схемы, числовые ограничения, состав файлов и согласованность сохранённых данных.

## Новый эксперимент

Для нового запуска создаётся локальный файл `.env` на основе `.env.example`; значение `LLM_AUTH_TOKEN` в репозиторий не добавляется. Новый результат рекомендуется сохранять в отдельный каталог:

```bat
set PYTHONUTF8=1
cd lab1_dpo
..\.venv\Scripts\python.exe run_lab.py --output output_second --seed 43
```

Значение seed воспроизводит расписание городов и порядок вариантов, но не гарантирует совпадение ответов вероятностной модели.

## Ограничения

Стратификация обеспечивает баланс по городам, но не делает выборку репрезентативной для реальной совокупности слушателей ДПО. Все заявки являются синтетическими и используются только в учебных целях.
