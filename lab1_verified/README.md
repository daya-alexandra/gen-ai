# Лабораторная № 1. Синтетические заявки на курсы ДПО

Курс «Практическое применение генеративного ИИ», домашнее задание к семинару 2.
Генерация выполнена 19 сентября 2026 года через API DeepSeek. В архиве находятся
код, результаты двух прогонов и проверка сохранённых данных. Повторная генерация
для просмотра или сдачи этих результатов не требуется.

## Результат

Основной набор — `lab1_dpo/output/stratified/`: 50 валидных заявок,
по 5 на каждый из 10 городов. Наибольшая доля специальности — 32%,
что ниже предела 35%. Сравнительный набор — `lab1_dpo/output/random/`.
Исходные ответы сохранены в `trace.jsonl`.

Дополнение — стратификация по городам и сравнение распределения специальностей.
Для соблюдения основного требования «50 заявок» использованы квоты 5 × 10.
Пример 10 × 10 из раздела «отлично» исходного задания дал бы 100 заявок.
Выбранное согласование двух указаний описано явно; оценку выставляет преподаватель.

## Проверка без API

Нужен Python 3.11 или новее. Открой CMD в папке с этим README.
Если зависимости ещё не установлены:

```bat
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

15 тестов первой лабораторной и проверка реальных сохранённых результатов:

```bat
.venv\Scripts\python.exe run.py check
.venv\Scripts\python.exe run.py verify
```

В выводе проверки результатов должно быть `"status": "passed"`.
Обе команды работают без ключа, не обращаются к API и не меняют результаты.
Запуск автоматически включает UTF-8 для дочерних процессов на Windows.
В Linux/macOS используй `python3 -m venv .venv` и `.venv/bin/python`.

## Новые эксперименты

Скопируй корневой `.env.example` в `.env`, заполни `LLM_AUTH_TOKEN` разрешённым
ключом. Расходуется баланс владельца API-аккаунта. `LLM_BUDGET_USD=5` —
верхняя оценка расходов этого комплекта, а не банковская выписка.
История расходов прежнего компьютера не входит в архив: отдельная копия
не учитывает ранее потраченные средства.

Для нового эксперимента сохраняй результаты в отдельный каталог:

```bat
set PYTHONUTF8=1
cd lab1_dpo
..\.venv\Scripts\python.exe run_lab.py --output output_second --seed 43
```

Команда `python run.py lab1` из корня продолжает старый прогон через `--resume`.
Для завершённых наборов она перестроит графики и автоматические выводы,
перезаписав дополненные тексты. Для обычной проверки используй `verify`.

`schema.py`, `prompts.py`, `generator.py`, `llm_client.py` сохранены в версии
реального прогона. Seed 42 воспроизводит расписание городов и порядок вариантов,
но не гарантирует повторение ответов API. В журнале записано имя модели из
запроса `deepseek-flash`; отдельный серверный номер версии не сохранён.
