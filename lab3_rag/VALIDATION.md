# Проверка перед API-прогоном

19.09.2026, Python 3.12, Linux. **12 локальных тестов пройдены** командой `python -m unittest test_lab3 -v`.

Проверены формальные размеры корпуса и gold, точное fixed-size разбиение, отсутствие потерь текста и ограниченное перекрытие, выбор границы абзаца, отказ от некорректного overlap, отсутствие завышения метрики повторяющимися чанками источника, выбор релевантного блока BM25, неверный chunk_id, невидимая часть документа, правила отказа при недостаточном контексте, обнаружение подмены результатов retrieval и полный конвейер генерации на заглушке.

Интеграционный тест получает 60 явно тестовых ответов, намеренно вызывает одну ошибку цитирования, проверяет повтор запроса, аудит, отсутствие повторных вызовов при возобновлении и обнаружение изменения окончательного ответа. Проверка по умолчанию отклоняет заглушку как неподходящее доказательство API-прогона. Тестовые ответы не включены в опубликованный `output/`.

Настоящее локальное измерение поиска выполнено и повторно проверено независимым пересчётом. В `output/` опубликованы его реальные индексы, ранжирование, метрики и отчёт. Подлинных результатов DeepSeek для третьей работы пока нет. Windows-сценарий подготовлен для CMD; в этой Linux-среде он не исполнялся.
