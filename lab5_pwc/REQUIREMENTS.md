# Соответствие заданию семинара 6

| Требование | Реализация | Проверка / ограничение |
|---|---|---|
| validate_plan между Planner и Worker | schemas_pwc.py, orchestrator.py | Два фантомных инструмента, id, зависимости и циклы; до исполнения |
| Перепланировка с feedback | planner.py, orchestrator.py | Неправильный план не отправляется исполнителям |
| _topological_levels, execute_level | schemas_pwc.py, worker.py | Проверены уровни, реальная конкуренция и изоляция зависимостей |
| Ускорение Q1 и дополнительного вопроса | benchmarks.py, Q1/Q5, 3 пары | Реальное время появится после API; не обещается ускорение |
| 5 битых входов, T0/T0.7, N=10 | critic_cases.py, critic.py, run_lab.py | 100 отдельных запросов, без повторов внутри испытания; raw_trace не передаётся |
| Q1–Q3 + 3 новых | eval_pwc.py | Q4 — риск фантома; Q5 — 3 валюты; Q6 — бюджет учебных API |
| 3 конфигурации × N=5 | run_lab.py | 90 реальных запусков, одинаковые критерии |
| Гарантированное исправление Q4 | validator_control.py | Гарантия для фиксированной инъекции и скриптового исправления; отдельно от основной API-таблицы |
| Пять разделов отчёта | `run_lab.py`; результат в `output/report.md` | Таблицы из сохранённых результатов, без заданных заранее победителей |

Исходный стартер не может обеспечить вероятностную гарантию галлюцинации LLM. Поэтому гарантированный контроль не смешивается с основной оценкой. Окончательную трактовку этого пункта определяет преподаватель; заявлять гарантированное превосходство в обычном API-eval было бы неверно.

Q3 оценивается по корректному отказу: в исходных данных нет нужных месячных приростов. Все данные остаются учебным снимком; никакие недостающие месячные показатели не генерируются.
