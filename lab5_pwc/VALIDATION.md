# Локальная проверка

19.09.2026, Python 3.12, Linux. **11 тестов пройдены**, без обращения к DeepSeek или ЦБ. Полный вывод: [local_checks.txt](local_checks.txt).

Проверены два фантомных имени; неизвестные зависимости, циклы и повтор id; уровни графа; одновременное исполнение независимых workers (барьер подтверждает реальную конкуренцию); доступ только к заявленным зависимостям; отсутствие raw_trace в данных критика; перепланировка до любого исполнителя; повтор ошибочного узла вместе с потомками без повторения независимого ответа; согласованность вердикта и сохранение raw ok=True в измерении ложных принятий.

Интеграционный тест проходит весь сценарий: **90 запусков + 100 испытаний критика + 12 замеров** на скриптовом транспорте. Каждый повтор имеет собственный запрос; повторный запуск завершённого конвейера не добавляет обращений. Тестовый критик намеренно принимает все повреждённые входы: проверено, что программа считает 10/10 ложных принятий, а не исправляет эти числа. Проверка результатов отклоняет тестовую заглушку в обычном режиме и обнаруживает изменение сохранённых метрик.

Контролируемый эксперимент валидатора исполняется без API и отдельно от таблицы 6×3. Числа тестовой скорости и качества в готовый комплект результатов не включены.

Общие tools.py, schemas.py, agent.py, llm_client.py, suite_common.py и bootstrap.py совпадают с четвёртой лабораторной, где отдельно проверены инструменты, бюджет, таймаут, защита от повторного запуска и перенос локального ключа.

Реальный API-прогон ещё не выполнен. Полезность PWC, ложные принятия и ускорение будут определены только по пользовательским результатам. Windows CMD подготовлен и проверен чтением кода; Windows-сценарий и ветка msvcrt в Linux не исполнялись. CSV сверены с исходными Git blob SHA-1. Ключей и выходов заглушки в архивах сборки нет.
