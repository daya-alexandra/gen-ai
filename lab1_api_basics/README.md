# Лабораторная работа № 1. Основы работы с API и промптинг

Работа выполнена по материалам семинара 1. Цель — освоить базовый вызов языковой модели через API, учёт токенов и управление ответом с помощью параметров генерации и структуры промпта.

## Постановка задачи

В работе требовалось последовательно выполнить следующие эксперименты:

1. отправить первый запрос к модели и сохранить сведения об использовании токенов;
2. оценить объём собственного текста с помощью `tiktoken`;
3. сравнить ответы при `temperature=0` и `temperature=1,0`;
4. сопоставить zero-shot промпт, ролевую инструкцию, требование к формату и few-shot пример;
5. провести эксперимент prompt golf на пяти заголовках;
6. получить ответы для четырёх заданных персон;
7. оценить 20 заголовков в десяти повторениях и рассчитать среднее значение и стандартное отклонение.

## Реализация

Запросы выполняются через OpenAI-совместимый интерфейс DeepSeek. Для каждого этапа сохраняются полный ответ, идентификатор запроса, сведения об использовании токенов и статус валидации. После каждого принятого ответа обновляется локальный кэш, поэтому прерванный запуск может быть продолжен без повторного выполнения завершённых этапов.

Для числовой оценки заголовков используется отдельный разбор ответа. Нераспознанные значения не включаются в итоговую статистику и фиксируются в журнале ошибок.

## Запуск

Требуется Python 3.10 или более новая версия. На Windows запуск выполняется файлом `RUN_LAB1.cmd`. Сценарий создаёт виртуальное окружение, устанавливает зависимости, запускает локальные тесты, выполняет эксперимент, проверяет результаты и формирует архив `lab1_results.zip`.

API-ключ задаётся локально в файле `.env`:

```text
LLM_AUTH_TOKEN=...
```

Файл `.env` не включается в репозиторий. При повторном запуске используются ранее сохранённые валидные ответы. Изменение кода или входного набора во время незавершённого эксперимента не предусмотрено.

Защитные параметры по умолчанию:

```text
LLM_MAX_CALLS=280
LLM_BUDGET_USD=1
```

Эти значения задают программные ограничения, а не фактическую стоимость эксперимента.
