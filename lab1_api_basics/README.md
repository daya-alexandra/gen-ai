# Лабораторная № 1 — основы API и промптинга

Подготовлена по материалам первого семинара. Комплект выполняет собственный API-прогон и не использует опубликованные преподавателем PNG/CSV как результат студентки.

## Что выполняется

- первый запрос и учёт токенов;
- оценка собственного текста через tiktoken;
- 10 ответов при T=0 и 10 при T=1,0;
- лестница zero-shot → роль → формат → few-shot;
- prompt golf на пяти заголовках;
- четыре персоны;
- 20 заголовков × 10 оценок, среднее, стандартное отклонение и график.

Всего при чистом запуске ожидается **234 ответа API**. Прогресс сохраняется после каждого ответа. Кэш не превращает один запрос в десять повторов: у каждого повтора свой stage.

## Запуск на Windows

Дважды нажми **RUN_LAB1.cmd**. Сценарий установит зависимости, выполнит локальные тесты, перенесёт ключ из соседней лабораторной либо откроет `.env`, затем проведёт эксперимент, проверит результат и создаст `lab1_results.zip`.

Ключ в чат не отправляй. При сетевой ошибке снова запусти тот же CMD: уже завершённые этапы повторно не оплачиваются. Не меняй код или `input/headlines.csv` посередине прогона.

По умолчанию установлены защитные пределы `LLM_MAX_CALLS=280` и `LLM_BUDGET_USD=1`. Это программные максимумы, а не ожидаемая стоимость.

## После прогона

В `output/` появятся `report.md`, JSON с полными ответами, `headlines_scored.csv`, два PNG, журнал API, usage и расчёт стоимости. Пришли `lab1_results.zip` для содержательной проверки перед сдачей.
