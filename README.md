## Лабораторная № 3 — RAG и сравнение чанкинга

[Код, корпус и инструкция запуска](lab3_rag/README.md).

**API-прогон завершён, отчёт доработан.** На 5 документах и 30 вопросах сравниваются блоки по 2000 символов без перекрытия и разбиение по границам текста с окном 800 и перекрытием 120. hit-rate@5 = **0,9000 у обеих стратегий**. Сохранены 60 итоговых ответов DeepSeek: у каждой стратегии 22 ответа и 8 отказов при недостаточном контексте. Статус «ответ дан» не означает автоматически правильный ответ.

В отчёте разобраны Q15 и Q17, где B получила нужные факты, и Q19, где лучше сработала A. Для каждого случая приведены конкретные чанки и их ранги. Исходные ответы, цитаты, токены и метрики сверены с журналом и кэшем; повторного API-прогона для оформления отчёта не было.

- [История эксперимента и ограничения](lab3_rag/PROTOCOL.md)
