## Итоговый проект — Academic Navigator

Система анализа и маршрутизации обращений магистрантов на полностью синтетических данных. В одном проверяемом конвейере объединены structured IE, BM25/RAG, агент с тремя локальными инструментами, разделение четырёх ролей и LLM-as-judge. Оценочный набор содержит 20 обращений; проверяются итоговый ответ, источник@3 и путь решения. Цитаты и числовые утверждения проходят программную grounding-проверку.

**Статус:** код и 7 локальных тестов готовы; требуется API-прогон минимум из 80 ответов.
