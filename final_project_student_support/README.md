# Итоговый проект — Academic Navigator

Учебная система анализа и маршрутизации обращений магистрантов. Проект объединяет structured IE, RAG, агентные инструменты, разделение ролей и LLM-as-judge. Все 20 обращений и пять регламентов синтетические; это не официальный сервис и не база правил реального университета.

## Что делает конвейер

1. Извлекает категорию, намерение, срочность, даты, чувствительные данные и точные цитаты.
2. Строит план только из трёх разрешённых инструментов.
3. Ищет правила через локальный BM25, получает контакт и при необходимости считает интервал дат.
4. Формирует ответ с дословными цитатами найденных источников.
5. Проверяет цитаты, числа и связь с source_id, затем передаёт результат независимому судье.
6. На 20 gold-примерах измеряет и правильность, и траекторию решения.

При чистом успешном запуске ожидается минимум **80 ответов API**: четыре роли на каждое обращение. Невалидный JSON или неподтверждённая ссылка могут вызвать повтор; предел — 160 ответов. Прогресс и каждый stage кэшируются отдельно.

## Запуск на Windows

Дважды нажми **RUN_PROJECT.cmd**. Сценарий установит зависимости, выполнит локальные тесты, перенесёт ключ из соседней лабораторной либо откроет `.env`, запустит проект, проверит результат и создаст `final_project_results.zip`.

Ключ в чат не отправляй. При сетевой ошибке просто повторно запусти CMD: сохранённые этапы не оплачиваются второй раз. Во время незавершённого прогона не меняй код и папку `input`.

Защитные ограничения `.env`: `LLM_MAX_CALLS=160`, `LLM_BUDGET_USD=3`. Это максимальные предохранители, а не ожидаемая цена и не рекомендация пополнить баланс на 3 доллара.

## Результат

В `output/` появятся:

- `report.md` — основной отчёт объёмом примерно 3–5 страниц;
- `results.json` и `cases/` — полные траектории 20 обращений;
- `evaluation.json`, `metrics.json` — проверка по gold и сводные показатели;
- `api_trace.jsonl`, `pipeline_trace.jsonl`, `validation_trace.jsonl` — аудит;
- `diagnostics.json` — три отдельно обозначенных контролируемых сбоя;
- `artifact_manifest.json` — SHA-256 сохранённых артефактов.

После строки **Finished** пришли `final_project_results.zip` для содержательной проверки отчёта перед сдачей.
