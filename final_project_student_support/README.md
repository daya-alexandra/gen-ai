# Итоговый проект — Academic Navigator

Учебная система анализа и маршрутизации обращений магистрантов. Проект объединяет structured IE, локальный BM25/RAG, агента с инструментами, разделение ролей и LLM-as-judge. Все 20 обращений и пять регламентов синтетические; это не официальный сервис и не база правил реального университета.

## Что делает конвейер

1. Извлекает категорию, намерение, срочность, даты, чувствительные данные и точные цитаты.
2. Строит план только из трёх разрешённых инструментов: `search_rules`, `get_contact`, `calculate_days`.
3. Ищет правила через локальный BM25, получает контакт и при необходимости считает интервал дат.
4. Формирует ответ только с дословными цитатами найденных источников.
5. Проверяет цитаты, числа и связь с `source_id`, затем передаёт результат независимому судье.
6. На 20 gold-примерах измеряет не только итоговый ответ, но и траекторию решения.

Невалидный JSON, неподтверждённая ссылка или ошибка схемы вызывают ограниченную повторную попытку. Прогресс и каждый stage кэшируются отдельно. В завершённом запуске сохранены 99 уникальных ответов API, полный usage и журнал валидации.

## Запуск на Windows

Дважды нажми `RUN_PROJECT.cmd`. Сценарий установит отсутствующие зависимости, выполнит локальные тесты, перенесёт ключ из соседней лабораторной либо откроет `.env`, запустит проект, проверит результат и создаст `final_project_results.zip`.

Ключ в чат и репозиторий не отправляй. При сетевой ошибке повторно запусти тот же CMD: завершённые этапы читаются из кэша и не оплачиваются второй раз. Во время незавершённого прогона не меняй код и папку `input`.

Защитные ограничения `.env`: `LLM_MAX_CALLS=160`, `LLM_BUDGET_USD=3`. Это максимальные предохранители, а не ожидаемая стоимость. Фактическая оценка завершённого прогона по сохранённому usage составляет $0,02119–$0,04239.

Повторный API-прогон для просмотра или сдачи текущего результата не требуется.

## Состав результата

В проверенном ZIP находятся:

- `report.md` — основной отчёт объёмом около 3–5 страниц;
- `results.json` и `cases/` — полные траектории 20 обращений;
- `evaluation.json`, `metrics.json` — gold-проверка и сводные показатели;
- `api_trace.jsonl`, `pipeline_trace.jsonl`, `validation_trace.jsonl` — аудит генерации и валидации;
- `diagnostics.json` — три отдельно обозначенных контролируемых сбоя;
- `cache/` — 99 исходных ответов API;
- `artifact_manifest.json` — SHA-256 всех сохранённых артефактов.
