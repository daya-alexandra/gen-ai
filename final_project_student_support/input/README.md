# Происхождение данных

Все 20 обращений и пять документов базы знаний созданы специально для учебного проекта. Это **синтетические данные**: они не содержат переписку реальных студентов и не описывают действующие правила конкретного университета.

Фиксированная дата эксперимента — 19 сентября 2026 года. Она нужна для воспроизводимых расчётов сроков. Категории, ожидаемые источники и маршруты хранятся отдельно в `gold.json`; модель не получает этот файл во время решения.

База знаний намеренно невелика, чтобы можно было вручную проверить каждую ссылку. В production-варианте она должна заменяться утверждёнными документами образовательной организации с версиями и датами действия.
