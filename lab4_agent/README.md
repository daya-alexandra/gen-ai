# Лабораторная работа № 5. Макроэкономический агент с инструментами

Работа выполнена по заданию семинара 5. Цель — расширить ReAct-агента новым инструментом сравнения периодов, обеспечить подробное журналирование его действий и провести оценивание на десяти вопросах.

## Реализация

Агент использует шесть локальных инструментов для работы с учебным набором макроэкономических данных. Дополнительный инструмент `compare_periods` сопоставляет значение выбранной метрики в двух периодах и возвращает исходные значения, разность, отношение и источник данных.

Каждый запуск получает идентификатор UUID4. В `trace.jsonl` последовательно записываются время, номер шага, имя инструмента, аргументы, наблюдение и итоговый ответ. Журнал открывается в режиме добавления и сохраняет историю между запусками.

Оценочный набор включает:

- четыре исходных вопроса;
- два вопроса с обязательным использованием `compare_periods`;
- два сложных вопроса с неоднозначными датами или метриками;
- два прикладных макроэкономических вопроса.

Для диагностики отдельно воспроизводятся три контролируемых типа отказа: некорректный JSON аргументов, обращение к отсутствующему инструменту и деление на ноль. Эти примеры не включаются в показатели основного API-прогона.

## Результаты

| Показатель | Значение |
|---|---:|
| Вопросы в оценочном наборе | 10 |
| Пройденные вопросы после содержательной проверки | 10 |
| Сохранённые ответы API | 24 |
| Пройденные локальные тесты | 16 |
| Доступные инструменты | 6 |

Первичная автоматическая оценка составила 7 из 10. Проверка трасс показала, что три ответа содержали правильные значения, но были отклонены числовым парсером из-за типографского минуса и пробела в качестве разделителя тысяч. Исходные ответы и первоначальная оценка сохранены; причина расхождения зафиксирована в `API_REVIEW.json`.

## Данные

Используются четыре CSV-файла из материалов семинара со снимком на 22 апреля 2026 года. Часть значений помечена в исходных данных как модельная. Дата «сегодня» в вопросах фиксируется датой снимка.

Для запроса на точную дату выбирается последняя доступная запись, не превышающая эту дату. Показатель `cpi_yoy` трактуется как изменение год к году и не используется как помесячный индекс для расчёта накопленной инфляции.

## Запуск

Требуется Python 3.10 или более новая версия. На Windows используется файл `RUN_LAB4.cmd`. Сценарий создаёт отдельное виртуальное окружение, устанавливает зависимости, выполняет тесты, запускает оценивание, проверяет результат и формирует `lab4_results.zip`.

Ручной запуск из каталога `lab4_agent`:

```bat
set PYTHONUTF8=1
.venv\Scripts\python.exe -m unittest test_lab -v
.venv\Scripts\python.exe run_lab.py
.venv\Scripts\python.exe verify_results.py
.venv\Scripts\python.exe collect_results.py
```

Новый независимый эксперимент выполняется с параметром `--output output_v2`. API-ключ задаётся локально в `.env` и не включается в результаты. Параметры `LLM_BUDGET_USD=2` и `LLM_MAX_CALLS=300` являются программными ограничениями, а не ожидаемой стоимостью.

## Ограничения

Оценивание основано на фиксированном учебном снимке, а не на текущей официальной статистике. Контролируемые отказы подтверждают работу обработчиков ошибок, но не характеризуют частоту естественных ошибок модели.
