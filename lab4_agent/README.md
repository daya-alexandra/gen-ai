# Лабораторная № 5 — макроагент

**Реальный API-прогон завершён и проверен.** Получено 24 ответа DeepSeek; по содержанию и трассам пройдено 10 из 10 вопросов. Первоначальный счётчик показал 7/10 из-за типографского минуса и пробела-разделителя тысяч в трёх правильных ответах. Разбор сохранён в [итоговом отчёте](API_REPORT.md), а проверенный комплект — в [lab4_results_checked.zip](../lab4_results_checked.zip).

Работа соответствует [домашнему заданию семинара 5](https://github.com/daya-alexandra/gen-ai/blob/main/семинар_5/домашнее_задание.md), поэтому в официальной сквозной нумерации это лабораторная № 5. Имя папки `lab4_agent` сохранено как техническое наследие первоначальной нумерации и не меняет содержание работы.

## Запуск на Windows

1. Распакуй `labs_remaining_ready.zip`. Папки `lab4_agent` и `lab5_pwc` можно положить рядом с уже существующими `lab2_text` и `lab3_rag` в `gen-ai-main`.
2. Открой **RUN_LAB4.cmd** двойным щелчком. Командную строку от администратора открывать не нужно: сценарий сам переходит в правильную папку и включает UTF-8.
3. Сценарий установит зависимости и выполнит локальные тесты. Затем он перенесёт ключ и адрес API из соседней лабораторной, если они есть. Если нет — откроется Блокнот: заполни `LLM_AUTH_TOKEN`, сохрани `.env`, закрой Блокнот и нажми любую клавишу в окне сценария. Ключ в чат не отправляй.
4. Дождись строки **Finished**. В папке появится **lab4_results.zip**. Этот прогон уже выполнен; повторять его для готового отчёта не требуется.

Нужен Python 3.10+. Виртуальное окружение создаётся отдельно для работы. Не заменяй файлы работающего эксперимента во время выполнения.

Внутри обычного eval: 10 вопросов, до 8 шагов модели на вопрос. Ошибочный ответ модели не прерывает всю оценку: он сохраняется как FAIL для анализа. Проблема доступа, сети или лимита останавливает запуск; после её устранения запусти тот же CMD. Готовые этапы и ответы API используются повторно. Новые вопросы/код/данные требуют нового `--output`.

## Что реализовано

- Пять базовых инструментов и `compare_periods`: шесть метрик, сравнение дат/месяцев, delta и ratio, происхождение данных, обработка нулевого знаменателя.
- Настоящие tool calls DeepSeek: функция выполняется локальным Python-кодом, её наблюдение возвращается модели с соответствующим tool_call_id.
- `trace.jsonl` в режиме append: UUID4 для каждого агентного запуска, время, шаг, имя, аргументы, наблюдение и итоговый ответ.
- 4 стартовых + 6 новых вопросов: два обязательных сравнения, два трудных и два практических.
- Три отдельных намеренных сбоя с реальными обработчиками ошибок: битый JSON, выдуманный инструмент, деление на ноль. Их транспорт скриптовый, это не ответы DeepSeek.
- Автоматический отчёт по четырём пунктам задания, проверка происхождения ответов по кэшу и API-журналу, архив без ключей.

Обычные ошибки API-eval и контролируемые сбои **разделены**. Если в обычном прогоне не возникнет трёх разных ошибок, отчёт не будет утверждать обратное. Диагностика намеренных поломок следует упражнению «ломаем агента» семинара; при требовании преподавателя именно спонтанных ошибок модели потребуется дополнительный эксперимент.

## Данные и даты

Используются неизменённые четыре CSV из стартера преподавателя, снимок **2026-04-22**. «Сегодня» в вопросах закреплено за этой датой, чтобы одинаково воспроизводить сравнения. Это учебные данные; часть ставок и инфляции помечена в стартере как mock. Маркер `mock_from_here` распространяется на последующие строки.

Курс на точную дату берётся из последней записи **не позже** этой даты; фактическая дата и отставание возвращаются отдельно. Например, для 2022-01-01 доступна запись 2021-12-15, а не будущая 2022-01-15. Для периода YYYY-MM используется конец месяца (текущий месяц ограничен датой снимка), а не среднее значение.

Инфляция `cpi_yoy` — **год к году**, а не помесячный прирост. Из неё нельзя считать накопленную инфляцию произведением месячных индексов. Данные не выдаются за текущую официальную статистику.

## Лимиты и стоимость

В `.env.example`: `LLM_BUDGET_USD=2`, `LLM_MAX_CALLS=300`. Это предохранители для всей лабораторной, **не цена работы и не требуемая сумма пополнения**. Автоматический перенос ключа не копирует старые лимиты второй/третьей работы. Уже существующий `.env` не перезаписывается.

Для оценки используются опубликованные на 19.09.2026 тарифы Flash: вход без кэша $0.30, вход из кэша $0.006, выход $1.20 за миллион токенов в пиковые часы; вне пика половина. Источник: [DeepSeek Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing/). Лимит не является банковской блокировкой: это оценка по токенам и консервативному резерву. При таймауте неопределённый расход остаётся зарезервированным.

## Команды вручную

Из папки `lab4_agent`, после установки `requirements.txt`:

```bat
set PYTHONUTF8=1
.venv\Scripts\python.exe -m unittest test_lab -v
.venv\Scripts\python.exe run_lab.py
.venv\Scripts\python.exe verify_results.py
.venv\Scripts\python.exe collect_results.py
```

Отдельный вопрос: `python agent.py "Во сколько раз вырос курс USD с января 2022 по апрель 2026?"`. Новый независимый эксперимент: `python run_lab.py --output output_v2`; затем укажи тот же `--output` при проверке и сборе архива. `verify_results.py` не обращается к API и по умолчанию отклоняет результаты на заглушке.

`MACRO_DATA_MODE=live` доступен только для отдельных интерактивных запросов: FX пробует ЦБ и при ошибке возвращается к учебному CSV. Остальные показатели всё равно берутся из учебного архива. Полный eval допускает только `snapshot`, чтобы не смешивать текущие и учебные данные.

`output/report.md` — отчёт; `eval_results.json` — ответы и критерии; `trace.jsonl` — шаги; `generation/` — исходные ответы API, usage, кэш и бюджет; `diagnostics/` — отдельные контролируемые сбои. Манифест фиксирует байты файлов. Проверка подтверждает согласованность локальных артефактов и заданных критериев, а не серверный биллинг и не полную смысловую правильность.

Для завершённого прогона используй [API_REPORT.md](API_REPORT.md). Исходные артефакты в проверенном архиве сохранены без изменений; [API_REVIEW.json](API_REVIEW.json) фиксирует хеш исходного архива и причину трёх ложных отрицаний автоматического счётчика.
