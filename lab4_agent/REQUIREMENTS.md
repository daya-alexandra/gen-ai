# Соответствие заданию семинара 5

| Требование | Реализация | Что остаётся после подготовки |
|---|---|---|
| compare_periods, 6 метрик | tools.py; существующие get-функции; схемы в schemas.py | Посмотреть ответы Q5, Q6, Q8 через API |
| Лог JSONL, UUID4, append | `agent.py`; результат в `output/trace.jsonl` | Получить реальные трассы |
| 4 + 6 вопросов | eval.py, 10 CASES; 2 сравнения, 2 трудных, 2 практических | Реальная таблица прохождения |
| 3 различных ошибки | diagnostics.py: JSON / неизвестный инструмент / ошибка вычисления | Контролируемые ошибки отделены от спонтанных; при строгом требовании только ошибок LLM нужен дополнительный эксперимент |
| Короткий отчёт | `run_lab.py`; результат в `output/report.md`, 4 раздела | Проверить сгенерированный отчёт и уточнить содержательный разбор ответов |

Локальные тесты подтверждают работу кода, а не качество ответов DeepSeek. Упоминание правильного инструмента само по себе не даёт PASS: нужны успешное наблюдение, ожидаемые числа и оговорка об учебном источнике.
