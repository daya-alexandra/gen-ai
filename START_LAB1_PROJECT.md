# Запуск лабораторной № 1 и итогового проекта

Обе работы подготовлены к собственному API-прогону. Они используют один формат `.env`, умеют переносить ключ из соседней лабораторной и сохраняют прогресс после каждого ответа.

## Сначала лабораторная № 1

1. Открой папку `lab1_api_basics`.
2. Дважды нажми `RUN_LAB1.cmd`.
3. Если откроется Блокнот, вставь ключ только после `LLM_AUTH_TOKEN=`, сохрани и закрой файл.
4. Дождись строки `Finished` и сохрани `lab1_results.zip`.

Чистый запуск ожидает 234 ответа API. Он оценивает 20 заголовков по 10 раз и выполняет остальные упражнения семинара. Уже завершённые stages при повторном запуске берутся из кэша.

## Затем итоговый проект

1. Открой папку `final_project_student_support`.
2. Дважды нажми `RUN_PROJECT.cmd`.
3. Ключ обычно найдётся в соседней лабораторной; если нет, откроется локальный `.env`.
4. Дождись строки `Finished` и сохрани `final_project_results.zip`.

При чистом успешном проходе проект получает минимум 80 ответов: четыре роли для каждого из 20 обращений. Повторы возможны только после ошибки JSON, схемы или grounding-проверки. Код ограничивает запуск 160 обращениями и оценочным верхним бюджетом 3 USD.

Не запускай две работы одновременно, не меняй код и входные данные во время незавершённого прогона. После сетевой ошибки запусти тот же CMD повторно. Никому не отправляй API-ключ, `.env` или снимок экрана с ключом.

После завершения пришли два архива результатов для содержательной проверки автоматических отчётов перед сдачей.
