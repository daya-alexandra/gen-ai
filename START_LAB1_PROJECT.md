# Техническая инструкция: лабораторная работа № 1 и итоговый проект

Проверенные результаты лабораторной работы № 1 и итогового проекта уже опубликованы в репозитории. Настоящая инструкция предназначена для независимого повторного запуска.

Обе работы используют единый формат `.env`, сохраняют прогресс после каждого принятого ответа и могут продолжить прерванный эксперимент по локальному кэшу.

## Лабораторная работа № 1

1. Перейти в каталог `lab1_api_basics`.
2. Запустить `RUN_LAB1.cmd`.
3. При отсутствии `.env` указать API-ключ в строке `LLM_AUTH_TOKEN=` открывшегося шаблона, сохранить файл и закрыть редактор.
4. Дождаться завершения тестов, эксперимента и итоговой проверки.

При чистом запуске ожидаются 234 валидных ответа API, в том числе 200 оценок заголовков. По окончании формируется архив `lab1_results.zip`.

## Итоговый проект

1. Перейти в каталог `final_project_student_support`.
2. Запустить `RUN_PROJECT.cmd`.
3. При необходимости заполнить локальный `.env`.
4. Дождаться завершения обработки 20 обращений и итоговой проверки.

По окончании формируется архив `final_project_results.zip`. Число обращений к API может превышать число примеров из-за разделения ролей и ограниченных повторных попыток при ошибках схемы или проверки источников.

## Условия безопасного запуска

- лабораторную работу и проект следует запускать последовательно;
- код и входные данные не изменяются во время незавершённого эксперимента;
- после сетевой ошибки используется тот же сценарий запуска, чтобы сохранить уже принятые ответы;
- API-ключ, файл `.env` и изображения с ключом не передаются третьим лицам и не добавляются в репозиторий.

Подробные сведения приведены в [`lab1_api_basics/README.md`](lab1_api_basics/README.md) и [`final_project_student_support/README.md`](final_project_student_support/README.md).
